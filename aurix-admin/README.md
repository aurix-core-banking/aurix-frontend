# Aurix Admin - Painel Administrativo

Painel administrativo do AURIX Core Banking com React Admin.

## Modulos

- Clientes, Contas, Transacoes, Investimentos, PIX, Compliance, Auditoria, Analytics

## Tecnologias

- React Admin 4.15.0, Material-UI 5, Recharts, React Router, Axios

## Instalacao

```bash
cd apps/frontend/aurix-admin
npm install
```

Configurar `REACT_APP_API_URL=http://localhost:8080`. Iniciar: `npm start`.
